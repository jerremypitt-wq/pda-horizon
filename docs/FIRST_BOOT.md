# Первое включение ПДА «Горизонт»

Что сделать, чтобы новый ПДА заработал и стал получать сообщения.
Время: ~5 минут. Заранее узнай у техника/организаторов: **регион LoRa,
модем-пресет и ключи закрытых чатов** (если есть).

## 0. Включи и дождись меню

После загрузки — 8 плиток: Общий чат, Группировка, Объявления,
Контакты, Открытые чаты, Досье, Настройки, Карта.
В шапке пока «Новичок» — это нормально, досье заполним ниже.

## 1. Настрой радио: Настройки → Мастер → Устройство (LoRa)

Вход в Настройки свободный. А раздел **Мастер** (радио, каналы, сброс) —
по мастер-PIN. Заводской: **0000**.

- **Регион LoRa** — как у всей сети игры (например, Россия (RU)).
- **Модем-пресет** — как у всей сети (обычно LongFast).
- **Хопы** — 3, если техник не сказал иначе.
- Нажми **Применить** и согласись на перезагрузку радиомодуля.

⚠️ Регион и пресет обязаны совпадать у всех устройств игры,
иначе ПДА чужой эфир просто не услышит.

## 2. Проверь каналы: Настройки → Мастер → Каналы чатов

- По умолчанию: Общий — канал 0, Группировка — 1, Объявления — 2.
- Если чат группировки закрытый — **ключ должен быть одинаковым
  на всех ПДА**, иначе сообщения не расшифруются.

## 3. Заполни досье: плитка Досье → кнопка 🔑 слева внизу

Правка тоже под мастер-PIN (0000, пока не сменили).

- Имя персонажа, **позывной**, ранг, группировка → **Сохранить**.
- Позывной увидят другие игроки в течение ~15 минут
  (досье рассылается по эфиру само).

## 4. Поставь дату и время: Настройки → Время

Вход свободный, PIN не нужен. Нужно для правильных меток у сообщений. Часы тикают сами
и переживают перезагрузку.

## 5. Проверь, что эфир слышно

Настройки → **Мастер → Инструменты Mesh → Детектор Mesh**:
через минуту-другую там должны появиться узлы сети.
Если детектор пуст — возвращайся к шагу 1
(регион/пресет не те) или отойди от глушилки/железобетона.

Дополнительно: открой **Общий чат** и попроси кого-нибудь
написать туда — сообщение должно прийти и пискнуть.

## 6. Закрой технику: смени мастер-PIN

Настройки → **Мастер → Мастер-пароль** → задай свой PIN вместо 0000,
чтобы игроки не лазили в радио и сбросы и не правили чужое досье.
Экран, время, звук и «О ПДА» при этом остаются доступны всем.

## Необязательное

- **Экран и тема** — яркость, тема, ориентация
  (ориентация применяется после перезагрузки ПДА — это штатно).
- **Звук** — набор «Тройной» стоит по умолчанию; там же бесшумный режим.

## Если что-то пошло не так

- Настройки → **Мастер → Сброс** (вход по мастер-PIN):
  «Сбросить настройки ПДА» — откат к заводским, PIN снова 0000;
  «Очистить историю чатов» — только сообщения.
- Версию прошивки видно в Настройки → О ПДА.
