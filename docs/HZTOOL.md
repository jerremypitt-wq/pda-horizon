# HzTool — инструмент техника (план)

PC-программа для обслуживания парка ПДА: подключил по USB — определила
чей аппарат, настроила, прошила. Живёт в `tools/hztool/` (рядом с
флэшером), Python + заморозка в `.exe` для полевых ноутбуков.

## Три столпа (откуда берутся данные)

1. **Meshtastic API по USB-serial** (`pip install meshtastic`, работает
   СЕГОДНЯ на 1.7.0 без изменений прошивки): `myNodeNum`, владелец
   (long/short name), версия приложения, каналы радио (имя/ключ),
   перезагрузка, полный пресет через YAML (`--configure`).
2. **HZ-протокол Горизонта** (нужна прошивка 1.8.0+): свои команды
   поверх USB-serial, префикс `HZ:`, ответы ключ=значение построчно.
   Даёт то, чего нет в Meshtastic API: версию Горизонта, досье
   (позывной/звание/группировка), `vbatScale`, заряд/милливольты,
   известные чужие досье. Перехват строк `HZ:` до/внутри консольного
   обработчика прошивки (деталь реализации 1.8.0).
3. **Флэшер** (`tools/flasher/` как модуль): прошивка до нужной версии
   из пакета (`flash.json` + бинари), `--skip-fs`/`--erase-all`.

## Что умеет (по фазам)

- **Фаза 1 — CLI, без прошивочных работ:** identify (узел/владелец/
  версии), каналы радио (имя/ключ через API), владелец, reboot,
  flash до версии, `--list-ports`. Проверка на живом ПДА сразу.
- **Фаза 2 — прошивка 1.8.0 + HZ:** чтение/запись досье и конфига,
  заряд батареи (предыгровая проверка «все выше 80%»),
  список известных досье. Хоcт-тесты протокола как обычно.
- **Фаза 3 — батч и GUI:** провижининг пачки аппаратов пресет-файлом
  (роль/команда → каналы+досье+прошивка одной командой); простая GUI
  поверх CLI-ядра (фреймворк — на фазе 3, не раньше).

## Приватность и доступ

- Историю чатов инструмент НЕ читает (технику она не нужна).
- HZ-протокол активен только при включённом тумблере
  «Настройки → Мастер → Режим техника» (persist, по умолчанию ВЫКЛ):
  чужой с кабелем без доступа в меню ничего не считает.
- Meshtastic API (каналы/владелец) — штатные возможности прошивки,
  тумблером не закрываются (как и сейчас через `meshtastic --setchan`).

## Риски/детали

- Версия pip-пакета `meshtastic` должна дружить с приложением 2.8.1:
  пинуем в `requirements.txt`, проверяем на железе.
- Заморозка `.exe` со всеми зависимостями (protobuf, pyserial,
  esptool-data) — по отработанной схеме `build_exe.bat` флэшера.
- HZ-протокол не должен ломать обычную консоль/логи прошивки:
  отвечаем только на строки с префиксом, чужое молча пропускаем.
