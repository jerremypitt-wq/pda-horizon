# План GPS для ПДА «Горизонт» — пока НЕ реализован

Согласованное направление (без изменений GNSS, радио и интерфейса в прошивке 1.14.0). Есть два вида ПДА: с внешним GPS LC76G на J13 и без него. **Одна прошивка** для обоих: ПДА без GPS должен принимать и показывать чужое местоположение на карте как точку с позывным. Наличие GPS на собственном ПДА не обязательно для приёма.

## Настройки и безопасность

- В защищённом разделе **Настройки → Мастер → GPS**: статус «модуль не установлен / выключен / поиск / координаты получены / нет связи / ошибка», установка/включение GPS (по умолчанию выключено), состояние подключения и качество/давность решения. При отсутствии модуля нет зависания и бесполезного опроса шины.
- Отдельное, **по умолчанию выключенное** разрешение «Передавать моё местоположение» (это не то же самое, что «GPS включён»). Явный выбор адресата или канала; первый этап — только ручное «Отправить позицию». Выключение немедленно прекращает отправку. Не обходить существующие права на отправку точек в общий канал.
- Не отправлять без действительного, достаточно свежего GPS-решения; показывать ошибку вместо прошлых координат. Держать точность и время получения рядом с точкой. Частоту автоматической отправки, если она понадобится, ограничить и согласовать отдельно (эфир, батарея, износ флеш-памяти).
- Физическое подключение LC76G на J13 (SCL/SDA/VCC/GND) проверять по конкретной купленной плате и заводской схеме; J13 разделён с тачем/RTC. Штатный UART-GPS платы на GPIO17/18 остаётся выключен из-за MAX17048. Не паять и не дорабатывать CrowPanel.

## Доставка и срок жизни точки

**Первый этап — совместимость со старыми ПДА:** GPS-ПДА пересчитывает широту/долготу в доли текущей карты и *по явному действию* отправляет точку существующим протоколом `HZ:POI:` (вкладка 0) либо `HZ:POI2:` (остальные). Название вроде «Позиция: <позывной>»; для обновления использовать стабильный ID автора, не создавать новый ID при каждом сеансе. Получатель без GPS видит обычную точку с позывным. Это **снимок**, а не живое наблюдение: обязательно указать время получения/отправки («Позиция на 14:32») в карточке/комментарии. Старые прошивки сохраняют такие точки в `net.csv`; автоматическая частая отправка недопустима: лимит 50 общих точек, уведомления и запись на флеш. У получателя со старой прошивкой нет автоматического истечения срока точки: не обещать временную точку там, где протокол её не умеет удалять.

**Будущий этап — действительно временная позиция:** отдельный версионированный пакет «позиция», с ID узла, временем, давностью, точностью и ограниченным временем жизни; получатели с обновлённой прошивкой хранят её в отдельном небольшом кеше, не в `pois.csv`/`net.csv`, отображают позывной и возраст, убирают маркер по TTL. После перезагрузки маркер не восстанавливается, пока не придёт новая позиция. Проверять авторство по узлу/каналу, порядок/повторы, ограничения пакета и не засорять чат. Для совместимости со старой прошивкой можно явно отправить обычную точку-снимок вместо временного пакета; не отправлять обе копии без дедупликации. Старые прошивки новый пакет не поймут.

## Геопривязка и карты

Сейчас `anchors` хранятся **только в `.hzmap` редактора** и на ПДА не загружаются. Перед внедрением GPS нужен отдельный валидируемый файл геопривязки на устройстве, связанный с постоянным ID вкладки и идентификатором/отпечатком конкретной карты. Его должен безопасно загружать HorizonMapStudio вместе с картой, а не сама прошивка. Для пересчёта — минимум три не лежащие на одной прямой опоры, проверка точности и выходов за границы; без надёжной калибровки **не рисовать выдуманную метку**. Если отправлять пиксельную точку по старому протоколу, оба ПДА должны иметь один и тот же проект карты и ID вкладки: иначе место на чужой карте неверно. GPS сам по себе этаж не определяет: вкладку выбирать вручную, для открытого пространства — соответствующую карту.

## Проверки до выпуска GPS

1. ПДА без модуля нормально включается, читает сообщения и принимает обычную точку GPS-ПДА; настройки GPS выключены по умолчанию.
2. Свежий и устаревший/отсутствующий GPS-fix, отсутствие карты, неверная геопривязка, несовпадающие карты и вкладки.
3. Права каналов/позывной, выключение передачи, повтор одного ID, лимит точек, порядок доставки, пропажа связи.
4. Для временного протокола: TTL, сон/перезагрузка, повторы/спам, отсутствие записей в `net.csv`, радионагрузка.
5. Испытать два реальных CrowPanel и выбранный LC76G на общей шине I²C; только после покупки и проверки питания/распиновки.

Решение о GPS-прошивке и новых пакетах будет приниматься отдельно; эта запись **не означает, что GPS уже работает**.
