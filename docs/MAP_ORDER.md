# ТЗ на карту и точки для игры «Забытые истории» (прошивка 1.7.5.ZI)

**Историческое ТЗ на первую карту (480×320).** Новая карта — 960×640; для нового материала используй `docs/MAP.md` и `games/zabytye-istorii/README.md`. Существующие точки 480×320 конвертируются автоматически.

Этот документ — для человека, который рисует карту и собирает точки.
Прочитай целиком, прежде чем делать. Если что-то непонятно — спроси, не гадай.

Карта показывается на экране ПДА 480×320. Точки рисует сам ПДА поверх картинки.

## Часть 1. Картинка карты

- Формат: **JPG**, обычный (baseline). НЕ прогрессивный, НЕ PNG.
- Размер: **ровно 480×320 пикселей**. Не больше, не меньше.
- Качество при сохранении: **85 и выше** (иначе при увеличении будет каша).
- Цвет: обычный (sRGB). Особых профилей не надо.
- Север — сверху. Если не так — напиши отдельно, куда смотрит верх.
- Мелкие детали и мелкий текст не класть: на экране ПДА их не прочитать.
  Проверка: открой JPG на телефоне во весь экран — если всё читается, годится.
- **Точки на картинке НЕ рисовать** — ни значки, ни названия, ни кружки.
  Их нарисует ПДА из таблицы (часть 2). Нарисованные на картинке точки дадут дубли.
- Край картинки = край игровой зоны. Что за краем — обрежь честно, без «продолжения».

## Часть 2. Таблица стартовых точек (Excel)

Один файл `.xlsx`, первый лист, первая строка — заголовки строго как ниже.
Порядок строк любой, пустых строк не оставлять. Лимит: **не больше 50 точек**.

| Колонка | Что писать | Правила |
|---|---|---|
| Тип | один из 5 (см. список ниже, буква в букву) | обязательно |
| Название | короткое имя точки | обязательно, **до 20 символов** (считая пробелы) |
| X | горизонталь, **в пикселях** | обязательно, целое число **0–479** (0 = левый край) |
| Y | вертикаль, **в пикселях** | обязательно, целое число **0–319** (0 = верхний край) |
| Отправитель | позывной или «Мастер» | обязательно |
| Комментарий | описание точки | можно пусто, **до 150 символов** (считая пробелы) |

Как снять X и Y: открой картинку в любом просмотрщике/редакторе, наведи мышь на место
точки — внизу обычно показываются координаты пикселя. Их и вписывай.

Разрешённые типы (писать точно так, с большой буквы):
1. Точка интереса
2. База
3. Опасность
4. Аномалия
5. Схрон

Пример заполнения:

| Тип | Название | X | Y | Отправитель | Комментарий |
|---|---|---|---|---|---|
| База | Бар «Сталкер» | 120 | 200 | Мастер | Нейтральная зона, вход с юга |
| Опасность | Воронка | 350 | 90 | Мастер | Не подходить ближе 10 метров |
| Схрон | Схрон 3 | 410 | 250 | Мастер |  |

## Часть 3. Проверка перед отправкой (чек-лист)

- [ ] Картинка — JPG, ровно 480×320, качество 85+, точек на ней нет.
- [ ] Таблица — .xlsx, заголовки как в части 2, точек не больше 50.
- [ ] Все X в пределах 0–479, все Y в пределах 0–319.
- [ ] Все типы — строго из списка пяти, без опечаток.
- [ ] Все названия — до 20 символов, все комментарии — до 150.
  (В Excel длина считается формулой `=ДЛСТР(ячейка)`.)
- [ ] У каждой точки заполнены: тип, название, X, Y, отправитель.

Присылай два файла: `map.jpg` + `pois.xlsx`. Имена файлов — любые, переименуем сами.
