ПДА "ГОРИЗОНТ" — КАК ПРОШИТЬ (2 минуты, ничего ставить не надо)

Что у тебя должно быть для прошивки 1.14.0 и новее:
  1. HorizonFlasher.exe — прошивальщик (старый редактор одной карты остаётся)
  2. horizon-Х.Y.Z.zip — универсальная прошивка БЕЗ игровой карты
  3. HorizonMapStudio.exe и проект .hzmap — отдельная программа и карта игры
  4. Этот файл.

Нужно: Windows 10/11, USB-кабель ДЛЯ ПЕРЕДАЧИ ДАННЫХ (не только зарядка!),
свободный USB-порт. Интернет не нужен, драйверы ставить не надо.

ВАЖНО: на ПДА два USB-C, и шьёт ТОЛЬКО верхний (OTG/J2)!
Нижний (CH340) — для зарядки и служебных логов, прошивка через него НЕ идёт.
Как проверить себя: в списке портов программы должен быть порт
с [303A:1001] в имени; если видишь только CH340 — кабель не в том разъёме.

ШАГИ:
  1. Подключи ПДА к компьютеру ВЕРХНИМ разъёмом (OTG/J2).
     При первом подключении Windows 1-2 минуты опознаёт устройство.
  2. Введи плату
     в режим прошивки: зажми BOOT, коротко нажми RST, отпусти RST
     и ДЕРЖИ BOOT (отпустишь, когда начнётся запись).
  3. Запусти HorizonFlasher.exe (двойной клик).
     При первом запуске Windows может показать синее окно
     "Система Windows защитила компьютер": нажми "Подробнее" ->
     "Выполнить в любом случае". Это нормально: программа новая,
     издатель ей пока не известен.
  4. Для обычной прошивки нажми "Обзор..." и выбери horizon-Х.Y.Z.zip
     (или ZIP обновления карты/точек).
  5. Проверь, что в строке "Порт" стоит "Авто" (порт найдётся сам).
     Номер COM может быть любым (COM4, COM5...) — это нормально.
  6. Если это ПЕРВАЯ установка на новый/полностью стёртый ПДА,
     поставь только «СТЕРЕТЬ данные: записать чистую файловую систему»:
     она подготовит место для карты. На уже используемом ПДА никаких
     галочек очистки не ставь: иначе потеряешь чаты, настройки и карту.
     Нажми ПРОШИТЬ. При ZIP карты отметь карту и/или точки и нажми ОБНОВИТЬ
     КАРТУ/ТОЧКИ; программа заранее сохранит резервную копию в Документах.
     Дождись "ГОТОВО" (чтение/проверка данных может занять несколько минут).
     BOOT можно отпустить, как только побегут проценты.
     Не отключай кабель, пока идёт запись!
  7. На новом ПДА открой HorizonMapStudio.exe, загрузи проект .hzmap,
     снова подключи ПДА через J2 в режиме BOOT и нажми
     «ЗАПИСАТЬ ВСЕ ВКЛАДКИ НА ПДА». До этого на нём нет карты — так задумано.
     Отключи ПДА. Готово, включай и пользуйся.

ЕСЛИ ЧТО-ТО НЕ ТАК:
  - "COM-порты не найдены": кабель без данных (возьми другой),
    кабель в нижнем разъёме (переткни в верхний/OTG), Windows ещё ставит
    драйвер (подожди 2 минуты и нажми "Обновить" в окне программы).
  - Программа выбрала порт с CH340 в имени: это нижний разъём,
    переткни кабель в верхний (OTG/J2) и нажми "Обновить".
  - "Failed to connect" / вечное "Connecting...": плату не ввели в режим
    прошивки — повтори шаг 2 (BOOT держать до старта записи) и снова жми
    ПРОШИТЬ. Если не помогло: другой кабель, скорость 460800.
  - Ошибка при обновлении данных: не удаляй копию из
    Документы/HorizonBackups и отправь продавцу лог и имя копии.
  - Окно упало: пришли продавцу свежий файл из папки %TEMP%
    с именем hzflash-error-*.txt (Win+R -> %TEMP% -> Enter).

Вопросы — продавцу, вместе с текстом из окна программы
(кнопка "Сохранить лог").

КАК НАРИСОВАТЬ ТОЧКИ И ОТПРАВИТЬ КАРТУ БЕЗ ПРОШИВКИ:
  - Для карт разных размеров нужна прошивка 1.8.6.ZI или новее. В главном окне нажми
    «ОТКРЫТЬ РЕДАКТОР КАРТЫ И ТОЧЕК» — ZIP выбирать НЕ нужно.
  - «Открыть JPG»: выбери JPG 3:2 от 480×320 до 960×640 (до 8 МиБ).
    На ПДА карта будет не более 720×480. Щёлкни по месту на карте, заполни
    карточку справа и нажми «Добавить / сохранить точку». Точку можно
    передвинуть мышкой. Старый pois.txt рядом с JPG загрузит прежние точки.
  - «Сохранить проект»: один файл .hzmap с картой и точками для будущих правок.
  - Подключи ПДА через J2 и нажми «ЗАЛИТЬ КАРТУ И ТОЧКИ НА ПДА».
    Программа сама узнает расположение данных, сохранит их копию в
    Документы/HorizonBackups и заменит только карту и СТАРТОВЫЕ точки.
    Чаты, свои и принятые точки останутся; прошивка не изменится.
    Если открываешь JPG без старых точек, прежние СТАРТОВЫЕ точки заменятся
    содержимым редактора, поэтому сначала сохрани нужные точки в проекте.
