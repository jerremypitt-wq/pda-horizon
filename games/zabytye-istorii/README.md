# Игра «Забытые истории» (прошивка 1.7.5.ZI)

Исходники игрового пакета от поставщика (как прислали, руками не править):

- `map.jpg` — карта, ровно 480×320, обычный JPG.
- `pois.txt` — стартовые общие точки, свободный формат:
  `N. Тип, Название, xNNN, yNNN, Отправитель, Комментарий.`

Требования к исходникам — в `docs/MAP_ORDER.md` (там описан Excel-вариант;
по факту поставщик прислал TXT — конвертер понимает только TXT).

Сборка: `tools/build/poi_pack.py` соберёт build-файлы (`map.rgb565` + `pois.csv`)
и `build.py` положит их в образ файловой системы прошивки (`/hzmap/`).
