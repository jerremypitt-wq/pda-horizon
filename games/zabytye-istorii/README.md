# Игра «Забытые истории» (прошивка 1.8.6.ZI)

Исходники игрового пакета (карта заменена владельцем на `map2.jpg`):

- `map.jpg` — исходный JPG 960×640; при сборке уменьшается до 720×480 (1,5× экран).
- `pois.txt` — стартовые общие точки, свободный формат:
  `N. Тип, Название, xNNN, yNNN, Отправитель, Комментарий.`

Требования к исходникам — в `docs/MAP_ORDER.md` (там описан Excel-вариант;
по факту поставщик прислал TXT — конвертер понимает только TXT).

Сборка: `tools/build/poi_pack.py` соберёт build-файлы (`map.rgb565` + сглаженный `map_preview.rgb565` + `pois.csv`)
и `build.py` положит их в образ файловой системы прошивки (`/hzmap/`).

`pois.txt` сохранён в старых координатах 480×320: конвертер переносит их через тысячные доли. Для новых точек в координатах исходного JPG используй `--poi-coordinates map`.
